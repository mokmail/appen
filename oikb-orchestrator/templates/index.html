Sync Local Directory

Browse the host filesystem, select a directory, and sync it with a knowledge base with one click. The directory will be mounted into the oikb container and added as a local source.

1. Select directory

Enter a path above and click Browse, or click a directory to navigate.

2. Configure sync

The source will be added to oikb.yaml with the container path as its source value. Get the KB ID from the Open WebUI knowledge base page (it's the UUID in the URL).
Mounts the directory into the oikb container, adds a local source entry, and triggers oikb sync.
